Privacy

隐私说明

Reference Check 可以在浏览器本地处理参考文献，也可以在部署了后台服务时把你选择的文件发送到同源后台进行解析和检查。后台模式用于更稳定地处理 PDF / Word 和 DOI 校验。

本地处理

静态模式下，`.pdf`、`.docx`、`.txt`、`.bib`、`.ris` 和 `.md` 文件会由浏览器读取。后台模式下，文件会上传到当前网站的同源后台接口 `/api/import-check`，用于提取参考文献并返回检查结果。当前后台实现不把上传文件写入持久存储。

在线 DOI 校验

点击“在线校验 DOI”时，应用会向 Crossref API 请求 DOI 元数据，用来判断 DOI 是否可解析。这个动作只在你主动点击后发生。

浏览器存储

应用会把当前输入临时保存在本机浏览器的 localStorage 中，便于刷新后继续检查。你可以点击“清空”删除这份本地缓存。
